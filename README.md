# 펫투데이 펫 서바이버 (뱀서류 팬게임)

브라우저에서 바로 도는 뱀파이어 서바이버즈식 게임. 펫투데이 공식 마스코트 파리·콩이·시리·레오가 주인공.

## 실행
- `index.html` 더블클릭 (또는 이 폴더에서 `python -m http.server 8765` 후 http://localhost:8765)
- 조작: WASD/방향키 이동, C 필살기, ESC 일시정지. 모바일은 왼쪽 드래그 + 오른쪽 버튼.

## 폴더
| 경로 | 내용 |
|---|---|
| `index.html` | 게임 본체 (단일 파일, 순수 Canvas/JS) |
| `00_브랜드자료/로고/` | 디자인 가이드 PDF, 로고 PDF/PNG, 파비콘 (원본: `\default\펫투데이_디자인팀\...\01-1_로고 및 캐릭터(펫투데이)`) |
| `00_브랜드자료/캐릭터/` | 패밀리 가이드 PDF, 캐릭터 원본 PNG/JPG |
| `01_스프라이트/` | 게임용으로 잘라낸 투명 PNG (높이 320px). `_raw/`는 분리 중간본 |
| `99_구버전_이모지프로토타입/` | 브랜드 적용 전 1차 프로토타입 (이모지 캐릭터) |

## 브랜드 적용 내역
- 색: PETODAY BLUE #293B8A(UI·필살기), GREEN #61CA84(경험치·포인트), SILVER #D1D3D5(배경 격자), BLACK #1D1D1B
- 서체: G마켓 산스(국문), Montserrat(영문·숫자) — 가이드 권장 서체
- 캐릭터: 패밀리 가이드 포즈 시트에서 추출 (가이드에 "응용하셔도 돼요" 표기). 외부 공개 전 CI 담당 검수 필요.

## 캐릭터 설계
| 캐릭터 | 기본 무기 | 필살기 | 비고 |
|---|---|---|---|
| 파리 (스피츠) | 축구공 슛 (튕기는 공) | 관심 집중! 간식 전부 끌어오기+전체 충격파 | 보물: 축구공·양말 |
| 콩이 (도베르만) | 농구공 덩크 (충격파) | 운동장 질주 5초 무적 돌진 | 체력 최고 |
| 시리 (푸들) | 고구마 던지기 (발사체) | 친구 응원 회복 50%+피해 2배 | 배려 컨셉 |
| 레오 (코숏) | 츄르 레이저 | 츄르 타임 회전 레이저 | 해금: 아무 캐릭터로 5분 생존. 포즈 1종뿐 |

공용 무기: 뼈다귀 부메랑, 삑삑이 오리(오라), 양말 투척, 사랑해 빔. 진화 Lv8/Lv18. 보스 3분·6분·9분.

## 2단계: 판 밖 성장 (완료)
- **재화**: 사료(공통) = 점수/8 + 생존 10초당 2 + 승리 150, 모드 배율(클래식 1 / 러시 1.3 / 무한 1.5). 츄르(캐릭터별) = 1분당 1 + 보스당 2 + 승리 3.
- **사료 상점** (전 캐릭터): 밥그릇(체력) · 산책 근육(피해) · 발톱(속도) · 코 감각(획득범위) · 스트레칭(쿨타임) · 유치원 졸업(시작 레벨) · 주인의 품(1회 부활) · 사료 할인 · 간식 응원(필살기 충전)
- **훈련** (캐릭터별): 체력 · 특기(기본 무기 시작 Lv) · 필살기 위력 · 덩치(범위)
- **모드**: 클래식(10분) / 러시(3분, 적 3배·체력 절반·경험치 2.2배, 해금: 클래식 5분) / 무한(끝없음, 3분마다 보스 순환·강화, 해금: 클래식 승리)
- **세이브**: localStorage `petoday_surv_save` 한 객체(사료·츄르·강화·훈련·모드별 최고기록). 1단계 기록은 자동 이관.
- 결과 화면에 획득 재화 표시, "같은 설정으로 다시" 버튼.

## 3단계: 완성도 (완료)
- **사운드**: Web Audio 합성(파일 없음). 효과음 12종 + 8비트 배경 루프. M키 / 🔊 버튼으로 음소거, 설정 저장.
- **레오 포즈 7종**: 원본 .ai(23.01.25) 21쪽에서 추출 → walk(선글라스)·hello·love(츄르)·down·play·sit·think
- **적 일러스트**: 이모지 대신 코드로 그린 플랫 벡터(검정 외곽선, 브랜드 색). 벼룩·진드기·털뭉치·청소기·천둥구름·박쥐 + 보스 3종
- **모바일/PWA**: `manifest.json` + `sw.js`(오프라인 캐시). HTTPS로 올리면 폰 홈화면에 설치 가능. 480px 이하 레이아웃 보정.
- **사료 보상 3배 상향**: 점수/2.5 + 생존 10초당 6 + 승리 500.
- **런타임 자산 폴더 `assets/`**(ASCII 경로): 스프라이트·로고·아이콘·G마켓산스 woff. `00_`·`01_` 폴더는 원본 보관용.

## 제품 연동 (라이트 PPL)
- **댕비앙**(pH9 프리미엄 알칼리수): 25초 후 첫 등장, 이후 40초마다 플레이어 근처에 1병 스폰 + 중형 적 처치 시 2% 드롭. 먹으면 체력 30% 회복 + 6초 이동속도 30%. 결과 화면에 마신 병 수 표시. 스프라이트는 `00_브랜드자료/제품/댕비앙 일러스트.ai`에서 추출.
- **향기나는 친환경 생분해 배변봉투**: 공용 무기 「배변봉투 지뢰」. 플레이어 주변에 봉투 롤을 깔고 적이 밟으면 범위 폭발. 이미지는 대표이미지 `(new)배변봉투.jpg`에서 누끼.
- **배너(2곳만)**: 타이틀 하단 "게임 속 댕비앙·배변봉투는 진짜 있어요 → 스마트스토어", 결과 화면 "지친 ○○에게 댕비앙 한 모금 → 댕비앙 상품 페이지(5982334170)". 승리 시 문구만 바뀜. 게임 중에는 광고 없음.
- 배변봉투 상품 링크는 미확인 → 스토어 메인으로 연결 중. 링크 받으면 교체.

## 배포
- **claude.ai 아티팩트**(지인 공유용): https://claude.ai/artifact/85CD6modPqsoKbaQNEjLsF — `dist/artifact.html`(스켈레톤 없이, 폰트 인라인) + `assets/` 파일로 발행. 비공개 기본이라 페이지의 Share 메뉴에서 공개/초대 필요.
- 재발행: `index.html` 수정 → 아래 빌드 → Artifact 도구로 같은 URL에 publish.
- 다른 선택지: GitHub Pages / Netlify Drop / Cloudflare Pages에 이 폴더(`index.html`, `assets/`, `manifest.json`, `sw.js`)를 올리면 PWA까지 동작.

```
cd dist && python build.py   # index.html -> dist/artifact.html
```
그 다음 Claude Code에서 "아티팩트 다시 발행해줘" (같은 URL 유지). 새 스프라이트가 늘었으면 files에 추가.

## 앱(스토어) 배포 가능성
- 지금은 웹(브라우저) 전용. 코드 변경 없이 **PWA**로 폰 홈화면 설치 가능(HTTPS 호스팅 필요, 아티팩트에선 불가).
- 구글 플레이/앱스토어 등록은 **Capacitor**로 이 폴더를 감싸면 됨(안드로이드 반나절, iOS는 맥·개발자계정 필요). 게임 로직은 그대로.
