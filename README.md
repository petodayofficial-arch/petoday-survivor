# 🐾 펫투데이 펫 서바이버

펫투데이 공식 마스코트 **파리 · 콩이 · 시리 · 레오**와 함께하는 브라우저 서바이버 게임.
몰려오는 벼룩 떼를 피해 간식을 주워 먹고, 전설의 반려동물로 진화하세요. 공격은 자동, 10분을 버티면 승리!

**▶ 플레이: https://petodayofficial-arch.github.io/petoday-survivor/**

- 이동 WASD / 방향키 · 필살기 C · 일시정지 ESC · 음소거 M
- 모바일: 화면 왼쪽 드래그 이동, 오른쪽 버튼 필살기. 홈화면에 추가하면 앱처럼 실행됩니다.
- 모드: 클래식(10분) · 러시(3분) · 무한
- 판 밖 성장: 사료 상점(공통 강화) · 츄르 훈련(캐릭터별)
